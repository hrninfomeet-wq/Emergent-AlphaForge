Confirmed: `premium_trigger_dispatch.py:293` detects valid premium-native strategy defaults; `plugins/premium_momentum.py:95` evaluates to an inert NONE signal, since the premium session engine drives it. Return explicit unsupported for premium-native strategies, including authored variants, rather than displaying NONE as a real signal. Critical causality hazard: `session_features.py:30` computes the complete opening range and exposes it over the whole session; historical per-bar evaluation on a complete frame can use later candles. `session_features.py:49` provides a separate ready index but requires the consumer to gate. For a preview at candle i, provide only the closed prefix ending at i to enrichment, `session_precompute` and `history_df` (and independently test prefix invariance); deny strategies whose inputs/session state cannot be satisfied. Do not assert historical parity just because helpers advertise causal. Session VWAP needs the session start; missing prior sessions affect gap/NR7/CPR and should return unavailable or a clear warmup warning, not confident signals.

## Proposed separate read-only contract

Candidate `POST /api/charts/analysis` body: instrument_key, timeframe, bounded history_limit, independent overlay IDs and optional strategy ID plus validated parameters. Resolve history through `ChartDataService.history` (`chart_data.py:323`, max 2000 bars); use explicit server-time and exchange-session-aware closure, excluding forming/incomplete buckets. Daily/weekly closure and session holidays need a trustworthy calendar; until defined mark unsupported rather than using fixed seconds. Validate strictly ordered bars, gaps, completeness, instrument/timeframe, volume availability and warmup; return explicit per-overlay/per-strategy unavailable reasons.

Response: resolved instrument, timeframe, history source/warnings, last_closed_bar_time and as_of/retrieval time; independent overlay outputs with type, time/price bounds, source and confirmation state; optional strategy ID/version/params, signal fields, and capability/unavailability reasons. S/R as current levels must not be painted retrospectively as known earlier; FVG boxes start at detection candle. No probability or edge claims can be derived from raw strategy score. No deployment, order, execution or broker mutation. Proposed shape only; route, persistence, user-facing predictions and score calibration are root architecture decisions.

Checks before implementation acceptance: synthetic prefix-invariance plus forming-bar removal at session boundaries; empty/missing/duplicate candles and warmup; volume-unavailable behavior; each supported strategy versus independent same-prefix evaluator; explicit premium/required-data rejection; no execution calls. Risk if assumptions fail: stale or future-derived analysis can influence a trade. Root owns architecture, tests and shared learning log.
